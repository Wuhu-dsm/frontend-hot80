# 红绿灯循环

> 分类：异步与设计模式  
> 环境：node + vitest

## 题目

实现红绿灯循环：红灯 N 秒 → 绿灯 N 秒 → 黄灯 N 秒，循环执行，并支持停止。

可用回调或日志记录当前灯色变化。
